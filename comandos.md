**inicializar repositorio**
git init

**verificar estado de los archivos**
git status 
git status -s

**añadir archivos al repositorios**
git add "name"
git add .
git add all
**hacer un comentario**
git commit -m "coment"
**subir los cambios a la web**
git push origin "ramaprincipal"
**comandos adicionales**
git config user.name
git config user.email
git config user.name "name"
git config user.email "email"

**verificando repositorio remoto**
git remote -v
**agregando repositirios remoto**
git remote add origin "urlrepo-github"
